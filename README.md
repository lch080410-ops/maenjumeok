# 맨주먹정신

> 칼? 마법? 필요 없어. 주먹이면 돼.

칼과 마법만 인정하는 나라 **검마국**에서 추방당한 소년 **한주먹**이, 무기 없이 주먹 하나로 왕국의 대성벽까지 뚫고 가는 가로 화면 횡스크롤 액션 게임.

## 스토리

- **세계관**: 열여섯 살이 되면 칼이나 마법을 증명해야 백성이 되는 검마국. 실패하면 성벽 밖 '추방자 마을'로 쫓겨난다.
- **대성벽의 정체**: 대마법사가 만든 결계. 추방자들의 기(氣)를 빨아들여 마법의 힘으로 쓴다.
- **숨겨진 역사**: 나라를 세운 영웅은 칼이 아니라 맨주먹의 '권왕'이었다. 대마법사가 역사를 '검왕'으로 조작하고 맨주먹을 금지했다. 주먹의 기는 결계를 깰 수 있기 때문.
- **인물**: 한주먹(주인공, 무기가 손에 안 붙는 건 사실 권왕의 기를 타고난 체질), 맨손 사범(권왕 계보의 마지막 사범), 레온(검술 수석 라이벌), 미나(시장의 정보상), 기사단장 그라함, 대마법사 벨라도르(흑막)

| 장 | 내용 | 승급 / 새 기술 |
| --- | --- | --- |
| 프롤로그 | 시험에서 동상 코를 베고 추방, 사범과 만나 수련 | 흰띠 |
| 1장 변두리 마을 | 끌려간 마을 사람들을 구하러 경비대 초소 돌파, "힘이 빠진다"는 첫 떡밥 | 노란띠 / 회오리 어퍼 **(구현됨)** |
| 2장 시장 거리 | 미나 합류, 라이벌 레온과 첫 대결 | 파란띠 / 땅 내려치기 |
| 3장 숲길 | 결계 기둥이 기운을 빨아들이는 현장 발견 | 빨간띠 / 권풍 |
| 4장 성 아래 마을 | 사범의 과거와 한주먹 체질의 비밀, 기사단장 그라함 | 검은띠 / 필살기 맨주먹 난타 |
| 5장 대성벽 | 레온 합류, 대마법사의 마지막 유혹, 결계 파괴 | 엔딩 |

## 플레이

`index.html` 하나로 돌아가는 웹 게임. 브라우저에서 열면 바로 실행된다. 폰은 가로로 돌려서 하는 걸 기준으로 만들었다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 왼쪽 조이스틱 / 방향키·WASD | 이동 (위아래로 줄 바꾸기) |
| 펀치 톡톡 / J·스페이스 | 좌우 잽 세 번 + 어퍼컷(적을 띄움). 연타하면서도 움직일 수 있고, 조이스틱을 반대로 꺾고 치면 돌아서 때린다 |
| 펀치 꾹 눌렀다 떼기 | 정권: 앞으로 돌진하는 강펀치. 방패와 벽을 부순다 |
| 어퍼컷 직후 펀치 (노란띠부터) | 회오리 어퍼: 몸을 돌려 띄운 적을 세 번 쓸어 올린다 |
| 회피 / K·Shift | 누르는 방향으로 휙 피하기 (방향 없으면 뒤로). 공격이 닿기 직전에 피하면 **완벽 회피**: 슬로우 모션 + 다음 한 방 반격 1.6배 |

## 설정

도장이나 일시정지 화면의 '설정'에서 조이스틱 크기(80~160%), 버튼 크기(80~150%), 버튼 진하기, 왼손잡이 모드(조작 좌우 반전), 진동, 소리, 화면 흔들림을 바꿀 수 있다.

## 게임 흐름

1. **오프닝 스토리**: 검술 시험에서 칼이 미끄러져 국왕 동상의 코를 베고, 마법 시험에서는 지팡이를 부러뜨려 추방당한다. 맨손 사범을 만나 주먹을 수련한다.
2. **도장 (홈 화면)**: 골드와 별을 확인하고, 출전하거나 몸을 단련한다.
3. **스테이지**: 오른쪽으로 나아가며 적을 쓰러뜨리고 길을 막는 벽을 부순다. 적과 벽에서 골드가 떨어진다.
4. **결과**: 별 3개 조건은 클리어, 체력 절반 이상 남기기, 제한 시간 안에 깨기. 쓰러져도 주운 골드는 챙긴다.
5. 도장으로 돌아와 몸을 단련하고 다음 스테이지에 도전한다.

## 띠 승급

장을 깰 때마다 사범의 승급 심사로 띠가 바뀌고(흰띠 → 노란띠 → 파란띠 → 빨간띠 → 검은띠) 새 기술을 배운다. 주인공 허리띠 색이 실제로 바뀐다.

## 몸 단련 (업그레이드)

무기는 없다. 몸이 무기다. 각 항목 최대 Lv.10, 비용은 레벨마다 약 1.55배.

| 항목 | 효과 |
| --- | --- |
| 주먹 단련 | 공격력 레벨당 ×1.12 |
| 굳은살 | 받는 피해 레벨당 -6% (최대 -50%) |
| 맷집 | 최대 체력 레벨당 +15 |
| 하체 단련 | 이동 속도 레벨당 +6% |
| 기 수련 | 정권 모으는 시간 레벨당 -7% |

## 적

모든 적은 머리 위에 체력바가 뜬다. 맞으면 깎인 부분이 잠깐 하얗게 남았다가 줄어든다.

- **기사**: 투구 틈으로 눈이 빛나는 왕국 경비병. 칼을 머리 위로 들었다 내리벤다. `!`가 뜨면 공격 직전.
- **방패병**: 큰 방패와 창. 잽을 막고 창으로 찌른다. 정권으로 방패를 깨야 한다.
- **마법사**: 후드 속에서 눈만 빛나는 흑마법사. 발밑에 마법진을 띄우고 불덩이를 쏜다. 주먹으로 쳐서 되돌려 보낼 수 있다.
- **보스 (경비대장 브루노)**: 콧수염에 흉터, 대검과 망토. 강한 공격과 돌진, 체력이 절반이 되면 부하를 부른다.

## 무기 유혹

스테이지 중간에 무기를 권하는 사람이 나타난다. **받으면 "맨주먹정신 위반!"으로 그 판은 실패하고 골드도 몰수.** 거절하면 맨주먹정신 포인트(공격력 +10%)를 얻는다.

## 앞으로 만들 것

- 2장 시장 거리, 3장 숲길, 4장 성 아래 마을, 5장 검마국 대성벽 (최종 보스 기사단장 그라함)
- 맨주먹정신 포인트로 배우는 특수기 (예: 회오리 어퍼컷)
- 그림·효과음 강화, 스테이지별 연출
- 출시: 웹(GitHub Pages / itch.io) → 구글 플레이 → 앱스토어

## 기술 메모

- HTML + Canvas + 순수 JavaScript, 파일 하나 (`index.html`)
- 진행 상황과 설정은 브라우저 `localStorage`(`mjj4-save`)에 저장
- 캐릭터: 관절(IK) 다리로 실제 발을 디디는 걷기. 움직인 거리만큼 걸음이 진행돼서 발이 미끄러지지 않는다
- 타격감: 히트스톱, 카메라 줌·흔들림, 만화 의성어(팍!·퍽!·쾅!!), 날아가는 적, 잔상
- 글꼴: Black Han Sans, Noto Sans KR (Google Fonts)
